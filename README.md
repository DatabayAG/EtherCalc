# ILIAS EtherCalc Plugin
* For ILIAS versions: 10.0

## Installation Instructions
1. Clone this repository to <ILIAS_DIRECTORY>/public/Customizing/global/plugins/Services/Repository/RepositoryObject/EtherCalc
2. After the plugin files have been installed as described above, ensure to run composer install in your ILIAS root folder.
3. Login to ILIAS with an administrator account (e.g. root)
3. Select **Plugins** from the **Administration** main menu drop down.
4. Search the **EtherCalc** plugin in the list of plugin and choose **Activate** from the **Actions** drop down.
5. Choose **Configure** from the **Actions** drop down and enter the required data.
